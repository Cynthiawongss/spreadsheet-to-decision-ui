# 为什么有利润，现金却减少了

## 输入需求

店主希望理解一个报告期的经营结果。用虚构 CSV 制作界面，说明利润、现金变化和期末资产分布，并保留三个视图间的数据关系。

| 项目 | 计算 | 结果（USD） |
|---|---|---|
| 利润 | 收入 1,000 − 已售商品成本 500 − 运营费用 200 | 300 |
| 现金变化 | 回款 600 − 供应商付款 1,100 − 运营支出 200 | −700 |
| 期末现金 | 期初 1,000 − 700 | 300 |
| 期末存货 | 期初 200 + 采购 1,000 − 已售成本 500 | 700 |
| 期末应收 | 收入 1,000 − 回款 600 | 400 |
| 期末应付 | 期初 100 + 采购 1,000 − 付款 1,100 | 0 |
| 期末资产 | 现金 300 + 存货 700 + 应收 400 | 1,400 |
| 期末权益 | 期初权益 1,100 + 利润 300 | 1,400 |

利润与现金的连接：**300 − 存货增加 500 − 应收增加 400 − 应付减少 100 = −700**。界面必须保留这个解释，不能只展示两张互不相关的数字卡片。

## 交互结果

打开 [中文版示例](index.zh-CN.html)，把回款从 600 调到 1,000：现金变成 700，应收变成 0，利润保持 300。调到 0 时，现金为 −300，显示资金缺口；重置回到回款 600。情景试算不修改源文件。

原始数据及来源位置见[字段映射](field-map.zh-CN.md)。这是有限范围的虚构经营案例，不接入付款系统，也不是完整法定财务报表。计算核对不能代替用户理解测试。
